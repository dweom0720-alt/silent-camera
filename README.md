# 무음카메라

갤럭시 기본 카메라처럼 쓰는 **무음** 카메라 앱입니다.

- 사진 / 동영상 / **범위촬영** 3가지 모드 (아래 모드 글자를 누르거나 화면을 좌우로 밀어 전환)
- 셔터·녹화 소리 없음 (대신 화면 깜빡임 + 짧은 진동)
- 범위촬영: 미리보기에 뜬 **직사각형**을 손가락으로 옮기고 모서리·변을 끌어 크기 조절 → 그 범위만 잘라 저장
  - 위쪽 `🔓 범위` 버튼으로 범위 고정(실수로 안 움직이게), `↺ 범위`로 초기화
  - 범위는 앱을 껐다 켜도 그대로 유지
- 플래시, 타이머(3·10초), 화면비(3:4·9:16·1:1), 격자선, 줌 버튼(.6·1·2·3), 두 손가락 확대, 눌러서 초점, 볼륨키 촬영
- **PDF 만들기**: 위쪽 `PDF` 버튼(또는 썸네일 길게 누르기) → 이 앱으로 찍은 사진을 고른 순서대로 압축 PDF로 저장 (고화질·보통·저용량·흑백문서), 저장 위치 `Download/무음카메라`
- **PDF 용량 줄이기**: PDF 화면의 `PDF 줄이기` 버튼, 또는 내 파일에서 PDF 여러 개 선택 → 공유 → 'PDF 용량 줄이기' → 한 번에 압축, `Download/무음카메라`에 `_압축`으로 저장 (원본 유지)
- 저장 위치: 사진·영상 `DCIM/Camera`, 범위촬영 `DCIM/범위촬영` (갤러리 앱에서 바로 보임)

## 설치·업데이트 (Obtainium)
1. Obtainium → 앱 추가 → 주소에 `https://github.com/dweom0720-alt/silent-camera` 입력 → 추가
2. 설치. 이후 코드가 바뀌면 Obtainium이 새 버전을 알려줌
